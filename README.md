# 서울시 대기 환경 및 대중교통(지하철) 이용량 상관관계 분석 (60222396 이준혁)

## 문제정의
기존의 미세먼지 분석은 단순히 농도 수치만을 확인하는 경우가 많다. 본 프로젝트는 미세먼지 농도와 기상 상황(강수량)이 서울 시민의 대중교통(지하철) 이용 패터턴에 어떤 영향을 미치는지 확인하는것을 목적으로 한다.

1. 미세먼지의 농도가 높거나 낮은 날 지하철 이용객의 수가 증가, 또는 감소하는가?
2. 강수량이 높거나 낮은 날 지하철 이용객의 수가 증가, 또는 감소하는가?
3. 평일과 주말에 따라 기상 변수의 영향력이 달라지는가?

## 빅데이터 분석의 필요성
미세먼지, 기상 데이터, 지하철 이용량 데이터는 시계열 데이터로, 수년간의 데이터를 취합할 경우 수백만 건 이상의 레코드가 발생한다. 즉, 이를 일반적인 로컬 환경에서 처리하기엔 한계가 있으므로, HDFS를 이용한 분산 저장과 Spark를 이용한 고속 분산 처리가 필수적이다.

## 사용 데이터
1. 미세먼지 데이터 : 한국환경공단(에어코리아) - 서울시 대기오염 측정 자료
2. 강수량 데이터 : 서울열린데이터광장(기상청) - 서울시 강수량 및 기상 관측 데이터
3. 지하철 이용량 데이터 : 서울열린데이터광장 - 서울시 교통카드 대중교통 이용량 정보

## 기술 스택
수집 및 저장: Python (데이터 전처리), HDFS (분산 저장), Apache Hive(HDFS 데이터를 SQL로 조회하기 위한 외부 테이블 매핑)
처리 및 분석: Apache Spark (PySpark), Spark SQL
자동화: Shell Script (데이터 자동 적재 및 파이프라인 제어)
분석 환경: Hadoop HDP Sandbox (PySpark 환경)

## 구현 계획
1. 데이터 수집 : Python 스크립트를 사용하여 Raw CSV파일(미세먼지, 지하철, 강수량 데이터) 확보 및 로컬 적재
2. 데이터 적재 및 테이블 매핑 : HDFS에 데이터를 분산 저장하고, Hive External Table을 생성하여 데이터 스키마를 정리 및 관리
3. 파이프 라인 구축 : run_pipeline.sh 스크립트를 통해 HDFS 자동 적재 및 분석 프로세스 통합
4. 데이터 정제 : Spark를 사용하여 결측치 처리, 데이터 타입 변환 및 노이즈 제거
5. 데이터 분석 : Spark SQL을 활용하여 다차원 분석 - 미세먼지/강수량/대중교통 이용량 간의 통계적 상관관계 파악
